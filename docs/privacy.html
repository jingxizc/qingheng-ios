中文

轻衡是一款本地优先的体重与饮食记录应用。开发者不运营用户账户、广告系统、分析平台或存储个人记录的自建服务器。

1. 本机保存的数据

  • 体重、目标体重、身高、称呼、饮食记录、饮食照片和应用设置；
  • 已绑定体重秤的本机标识，以及用于过滤异常读数的个人体重基线；
  • Qwen API Key，保存在仅限本设备且仅解锁时可访问的 iOS 钥匙串中。

这些数据默认留在设备上，不会发送给开发者。

2. Apple 健康

经你单独授权后，轻衡可以向 HealthKit 写入体重，并读取步数、活动能量、锻炼时长和睡眠时段。轻衡不会读取病历、心率或其他未在授权界面列出的健康类型。健康数据只用于体重趋势、昨日复盘和晨间建议，不用于广告、营销、数据经纪或信用判断。

3. 可选的 Qwen 云端 AI

云端 AI 默认未连接。只有当你自行提供 Qwen API Key 并主动使用相关功能时，轻衡才会从设备直接向你选择的 Qwen/DashScope 接口发送：

  • 你主动提交分析的饮食照片，以及份量和餐食说明；
  • 生成教练建议所需的体重、目标、饮食、运动和睡眠文字摘要；
  • 用于请求鉴权的 Qwen API Key。

轻衡不会向 Qwen 上传 HealthKit 原始样本。Qwen 对请求内容和账户标识的处理受其自身条款与隐私政策约束；开发者无法控制其保留周期。你可以不连接 Qwen，或随时在应用中移除连接，继续使用本机分析和本地规则。

4. 蓝牙、相机、照片和通知

蓝牙用于发现并读取兼容体重秤的广播；相机和照片权限用于创建饮食记录；通知用于你选择开启的晨间提醒。这些权限可在 iOS 设置中随时关闭。

5. 数据删除与保留

删除应用会删除其本地数据库、照片副本、设置和钥匙串配置。已经写入 Apple 健康的数据由 HealthKit 管理，可在“健康”App 中查看或删除。发送给 Qwen 的内容应依照 Qwen 的账户工具和政策处理。

6. 儿童、变更与联系

轻衡不是面向儿童设计的服务，也不提供医疗诊断。政策发生实质变化时，本页面会更新生效日期。隐私问题可通过 GitHub Issues 联系开发者。

English

QingHeng is a local-first weight and meal journal. The developer does not operate user accounts, advertising, analytics, or a custom server that stores personal records.

1. Data stored on your device

  • Weight, goals, height, display name, meal records, meal photos, and app settings;
  • The locally stored identifier of a paired scale and a personal baseline used to reject anomalous readings;
  • Your Qwen API key in the iOS Keychain, restricted to the unlocked device.

This data remains on your device by default and is not sent to the developer.

2. Apple Health

With separate permission, QingHeng can write weight to HealthKit and read steps, active energy, exercise time, and sleep intervals. It does not read clinical records, heart rate, or health types not shown in the permission flow. Health data is used only for weight trends and coaching, never for advertising, marketing, data brokerage, or credit decisions.

3. Optional Qwen cloud AI

Cloud AI is disconnected by default. If you provide your own Qwen API key and actively use an AI feature, QingHeng sends requests directly from your device to the selected Qwen/DashScope endpoint. A request may include a meal photo and portion details, text summaries of weight, goals, meals, activity, and sleep, and the API key required for authentication.

Raw HealthKit samples are never uploaded to Qwen. Qwen processes request content and account identifiers under its own terms and privacy policy, including any applicable retention. You can avoid cloud processing or remove the connection at any time and continue using on-device analysis and local rules.

4. Bluetooth, camera, photos, and notifications

Bluetooth discovers compatible scales; camera and photo access create meal records; notifications provide optional morning reminders. You can revoke these permissions in iOS Settings.

5. Retention and deletion

Deleting QingHeng removes its local database, copied photos, settings, and Keychain configuration. Weight samples already written to Apple Health are controlled from the Health app. Content sent to Qwen is handled through Qwen account tools and policies.

6. Children, changes, and contact

QingHeng is not designed for children and does not provide medical diagnosis. Material changes will update the effective date above. Contact the developer through GitHub Issues.
